# Media Archive｜影音典藏

以人物為入口，整理與探索音樂、影像及其他影音作品。

## 技術

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google 試算表

## 專案結構

```text
media-archive/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── config.js
│   ├── api.js
│   └── app.js
└── README.md
```

## 開始設定

1. 在 `js/config.js` 填入新版 Google Apps Script Web App 網址。
2. 使用 GitHub Pages 發布網站。
